# zhuyi-skills

Claude Code 插件市场仓库，每个文件夹是一个独立 skill 插件。

## Skills

| 插件 | 主要功能 |
|---|---|
| [model-switch](model-switch/) | 切换 Claude Code 模型提供商（GLM/Qwen/Kimi/DeepSeek/OpenRouter 等）：列出/状态/一键切换/逐项弹窗添加新提供商，自动备份、原子写入、token 脱敏 |

## 安装

```
/plugin marketplace add asdf112255/skills
/plugin install <插件名>@zhuyi-skills
```

详细使用说明见各插件目录内的 README。
